# Docs app notes

Repo-wide rules are in the root [AGENTS.md](../../AGENTS.md). This app is described in [README.md](README.md).

- Build the icon package before running this app: `pnpm build` from the repo root, then `pnpm dev:docs`.
- `data/` is generated by `scripts/generate-icons.mjs` and gitignored. Never edit it; change the script.
- Read icon data on the server through `lib/icons.ts`. Render icons through `iconMap` in `data/icon-components.tsx`. Do not read `packages/icons/icons-export.json`.
- `/llms.txt` and `/llms-full.txt` are static route handlers backed by `lib/llms.ts`. The guide text comes from `packages/icons/llms.txt`; edit it there.
- Usage docs shown on the site are in `components/docs-content.tsx`. Keep them consistent with `packages/icons/README.md` and `packages/icons/llms.txt`.
- This app is in the changeset `ignore` list. Changes here do not need a changeset.
